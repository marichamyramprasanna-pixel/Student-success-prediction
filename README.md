An end-to-end Machine Learning decision-support system and interactive web platform designed to predict student academic outcomes, explain individual risk factors, and recommend targeted early interventions for educators and academic advisors.

## 🌐 Live Interactive Web Prototype

Experience the zero-dependency client-side ML platform directly in your browser:

👉 **[Launch Live Demo](https://marichamyramprasanna-pixel.github.io/Student-success-prediction/)**

### Web Prototype Highlights
- **Zero-Data Clean State**: Launches with no fake or pre-populated student records, ensuring clean institutional testing from the first interaction.
- **SHAP-Style Feature Attribution**: Calculates exact log-odds contributions for every metric so advisors can see *why* a student is flagged as at-risk.
- **Dual GPA Scale Support**: Seamlessly toggle between **4.0** and **10.0** grading scales.
- **In-Browser ML Engine**: Upload custom CSV cohorts to either batch-score students or train a fresh **Logistic Regression** model via client-side Gradient Descent.
- **Royal Blue & Light Cream UI**: Accessible, high-contrast academic theme (`#002366` / `#1E3A8A` on `#FDFBF7` / `#F5F2EB`).

## 🏗️ System Architecture

The repository includes two complementary implementations:
1. **Client-Side Web Prototype (`index.html`)**: A standalone, browser-based analytical workspace for rapid individual assessments, CSV cohort scoring, and client-side model training.
2. **Python ML Pipeline & Streamlit App (`train_model.py` & `app.py`)**: A production-ready Scikit-learn pipeline utilizing `ColumnTransformer`, `StandardScaler`, `OneHotEncoder`, and a class-balanced `RandomForestClassifier`.

```text
Student-success-prediction/
├── index.html                   # Standalone interactive web platform (Royal Blue & Cream UI)
├── train_model.py               # Scikit-learn preprocessing, training & evaluation pipeline
├── app.py                       # Streamlit dashboard for Python model inference
├── student_success_model.pkl    # Serialized trained pipeline (generated by train_model.py)
